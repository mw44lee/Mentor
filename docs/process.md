# 멘토링 업무 프로세스

멘토의 표준 업무 절차입니다. 의뢰가 새로 들어오면 1~3장을 따라가고, 진행 중에는 의뢰 경로에 맞는 장을 회차마다 반복합니다.

- **창업 멘토링 (PLAB):** 4~6장
- **AI 멘토링 (혁신 소상공인 AI 활용지원 사업):** 7~9장
- 종료(10장)와 툴킷(11장)은 두 경로 공통입니다.

원칙: 확인되지 않은 사실·일정·결정은 임의로 정하지 않고 미결 사항에 올린 뒤 확인합니다.

## 1. 멘토의 역할

**솔루션 파트너이자 러닝메이트**

- **평가하지 않는다:** 멘티를 채점하지 않습니다. 구상이 올바른 방향으로 나아가 시장에 안착하도록 함께 고민합니다.
- **질문으로 돕는다:** 정답을 주입하지 않고, 핵심을 찌르는 질문으로 멘티 스스로 가설과 맹점을 마주하게 하고 검증 틀을 쥐여 줍니다.
- **사실로 정의를 바꾼다:** 구상이 틀렸을 때 억지로 꺾지 않고, 고객의 실제 행동(결제, 인터뷰, 파일럿 반응)을 함께 확인해 멘티 스스로 사업의 정의를 고치게 돕습니다.
- **숫자로 증명한다:** 효과는 "월 몇 시간을 아꼈는가", "외주비를 얼마 줄였는가", "주력 상품 판매 비중·객단가가 얼마나 올랐는가"로 보여 줍니다.
- **멘토가 떠나도 남게 한다:** 멘티(점주)가 멘토 없이 직접 계속 쓸 수 있는 방법과 도구를 남깁니다.

| 하는 일 | 하지 않는 일 |
| --- | --- |
| 비즈니스 가설 분해, 가장 취약한 전제 찾기 | 서비스 제작·디자인·기기 설치 대행 |
| 현장 검증 도구 제공 (인터뷰 질문지, ICP 점수표, 파일럿 설계표, AI 도입 진단표) | 영업 대행, 거래처 직접 소개 |
| 손익·단위 경제·투자 회수 기간·사업비 예산 검토 | 금전 거래 |
| 행정 마감과 필수 증빙 선제 관리 | 사전 승인 없는 자체 개발 지원 (운영기관에 범위 확인) |
| 회차마다 성실성·성장성·우수성 등 보고에 쓸 사실 메모 | 멘티 대신 콘텐츠·결과물을 만들어 주기 (실습은 멘티가 직접) |

| --- | --- | --- |
| 사업 | 모두의 창업 프로젝트 | 2026년 혁신 소상공인 AI 활용지원 사업 (중소벤처기업부·소상공인시장진흥공단) |
| 운영기관 | 서울창조경제혁신센터 (양식 기재), 플랫폼 PLAB ON | 서울창조경제혁신센터(주관), 제주·강원창경, 페이서파트너스 컨소시엄 |
| 구조 | 1:1 멘토링 | STEP 1 1:1 맞춤형 AI 멘토링(모델 구축) → 발표평가 → STEP 2 사업화 자금 최대 4,000만 원 (정부지원금 80%, 자부담 20%) |
| 표준 회차 | 확인 필요 | 3회차 (진단 → 구축·실습 → 효과 측정·사업계획) |
| 멘토링 목표 | 가설 검증으로 사업 정의를 다듬기 | AI 실전 도입과 STEP 2 사업화 자금 통과 |
| 보고 양식 | 양식3(회차별 멘토링 보고서), 양식4(책임멘토 관찰 의견서) | 확인 필요 (매뉴얼에 보고 양식 언급 없음) |
| 확인된 요건 | 오프라인 운영 원칙, 회차마다 사진 2장 이상, 양식3 내용 1,000자 이상, 양식4 1페이지 이내 | 회차별 결과물(진단표, 프롬프트 팩, 사업계획서 등 — 8장) |
| 이 문서의 장 | 4~6장 | 7~9장 |

- 양식 원본과 가이드는 `admin` 폴더에 보관합니다 (AI 멘토링 매뉴얼: `admin\AI활용지원사업`).

## 4. 멘토링 4단계 사이클

창업 멘토링(PLAB) 기준입니다. AI 멘토링은 7장을 따릅니다.

| 단계 | 하는 일 | 쓰는 도구 |
| --- | --- | --- |
| Phase 1. 가설 분해·진단 | 구상을 검증 가능한 단위 가설로 분해. 누가 돈을 내는가 / 왜 내는가 / 왜 계속 내는가. 가장 취약한 가정 3개 도출 | 쟁점·가설 메모 |
| Phase 2. 현장 발견·검증 | Mom Test 인터뷰(과거 행동·지출), 대체재 분석, ICP 점수화로 Beachhead 1곳 선정 | 템플릿 A·B |
| Phase 3. 파일럿 실험·측정 | 소수 대상, 기준값 vs 개선값 전후 비교, 내부 대조군. 소수 결과를 일반화하지 않음 | 템플릿 C |
| Phase 4. 사업 모델 안착 | 증명된 가치를 숫자로 환산해 가격·상품 구조 확정 | 템플릿 D |

## 5. 회차 운영 루틴

창업 멘토링(PLAB) 기준입니다. 미팅 후 기록 방법은 두 경로가 같습니다.

### 미팅 전
- 지난 과제 제출물 확인 (회차·기록 탭에 올라온 멘티 제출물)
- 이번 회차의 **가장 날카로운 질문(Killer Question)** 1~2개
- 타임테이블 예: 청취 20분 → 쟁점 토론 40분 → 프레임워크 설계 40분 → 숙제 합의 20분 (2시간 기준)
- 미결 사항 중 이번 회차에 확인할 것 고르기
- 회차·기록 탭에서 일시·장소·진행방법 확인

### 미팅 중
- **증빙 (PLAB):** 시작·종료 때 멘토·멘티 얼굴이 보이는 사진 각 1장, 시작·종료 시각 기록
- 멘티의 현장 경험을 먼저 20분 경청
- 질문으로 논리를 점검하고 프레임워크를 함께 채움
- 숙제는 행동 단위로: '점주 5명 만나기', '대체재 견적 3개 받기' + 마감일 + 점검 기준

### 미팅 후 (24시간 안, 두 경로 공통)
1. **회차·기록 탭의 해당 회차에 기록을 올립니다.** 메모, 사진, 문서, 녹음 변환본(.txt) 무엇이든 됩니다. 다른 회차 이야기가 섞여도 괜찮습니다.
2. **AI 정리 → 검토하고 반영.** 체크한 항목만 반영됩니다: 끝난 체크리스트, 새 체크리스트, 새 미결·결정, 일정, 회차 기본 정보(일시·장소·완료 표시).
3. 회차 기본 정보에서 시작·종료 사진을 지정하고 상태를 '완료'로 둡니다.
4. 보고서 탭에서 해당 회차 보고서 초안을 생성·검토합니다 (PLAB 6장).
5. 멘티에게 숙제와 다음 일정을 공유합니다. 멘토 전용 정보(수당, 킬러 질문, 관찰 메모)는 공유하지 않습니다.

## 6. 기록과 보고서

### 기록 원칙 (두 경로 공통)
- 근거 수준을 구분합니다: **가설**(검증 전) / **말**(의견) / **행동**(지출·신청·결제) / **사실**(확인됨).
- 녹음은 휴대폰 녹음 앱 등으로 텍스트로 변환한 파일(.txt)을 올립니다. (앱의 자동 받아쓰기는 OpenAI API 키를 넣었을 때만 동작)
- 원본 파일은 지우지 않고 보관합니다.
- AI 정리와 보고서 초안은 이 PC의 Claude Code 계정으로 만들어집니다. 근거 없는 내용은 쓰지 않고 '부족한 것'으로 알려 줍니다.

### 보고서 생성 (PLAB)
- **양식3 (회차별):** 기록 전체에서 해당 회차 내용만 뽑아 1,000자 이상으로 작성. 순서: 현황 → 주요 논의·멘토 의견 → 결과물 → 차기 과제.
- **양식4 (관찰 의견서):** 모든 회차의 근거로 성실성·성장성·우수성 작성, 1페이지 이내. 모든 회차가 끝난 뒤 생성.
- 초안이 마음에 들지 않으면 **피드백을 적고 다시 생성**하거나 직접 고쳐 저장합니다. 모든 버전이 남습니다.
- docx로 내려받아 hwp 원본 양식에 옮겨 제출합니다.

## 7. AI 멘토링 단계와 목표

혁신 소상공인 AI 활용지원 사업 기준입니다.

### 목표: 실전 도입과 STEP 2 사업화 자금(최대 4,000만 원) 통과
1. **소상공인의 진짜 병목 해결:** 신기술 체험이 아니라 점주가 매일 겪는 인력 부족, 마케팅 비용 부담, 디자인 품질 한계를 AI로 해결합니다.
2. **STEP 2로 이어지는 결과물:** STEP 1 멘토링 결과(AI 도입 전후 데이터)가 그대로 발표평가 자료와 사업계획서가 되도록 만듭니다.

### 대원칙
- **No-Code / Low-Code 우선:** 코딩이나 복잡한 개발 대신, 점주가 멘토 없이 매일 직접 다룰 수 있는 상용 SaaS AI 도구를 고릅니다.
- **비용 절감·매출 증대와 직결:** 절감 시간, 줄인 외주비, 객단가·판매 비중 변화로 증명합니다.
- **프롬프트 자산화:** 상호명·주력 메뉴·핵심 타깃만 넣으면 바로 결과가 나오는 맞춤 프롬프트 템플릿을 만들어 점주의 스마트폰·PC에 저장해 줍니다.

### 단계

| 단계 | 핵심 목표 | 결과물 |
| --- | --- | --- |
| 1회차 · 진단 & 과제 정의 | 워크플로우 분석, 집중할 AI 분야 1개 선정 | AI 도입 진단표, 과제 정의서 |
| 2회차 · 솔루션 구축 & 실습 | 맞춤형 AI 파이프라인 세팅, 소규모 현장 실험 | 멘티 맞춤 프롬프트 팩, 1차 파일럿 제작물 |
| 3회차 · 효과 측정 & BM 완성 | 도입 성과 수합, STEP 2 사업계획서 코칭 | STEP 2 사업계획서, 발표평가 PPT 초안 |
| 이후 · 발표평가 → STEP 2 | 사업화 자금 선정 | (사업 공지 기준 — 일정 등록) |

## 8. AI 멘토링 회차 운영 루틴

미팅 후 기록 방법은 5장 '미팅 후'와 같습니다. 회차마다 아래 결과물이 회차·기록 탭에 남아야 합니다.

### 1회차 · 진단 & 과제 정의
- **미팅 전:** 매장 업종·채널(배달앱, 플레이스, SNS) 파악, 현재 쓰는 도구와 외주 지출 확인 요청
- **미팅 중:** 점주의 하루 업무 동선과 지출 내역 점검 → 시간·비용이 가장 많이 드는 병목 3가지 도출 → 지원 분야 중 집중 영역 1개 확정
- **도입 전 기준값 기록:** 작업 1건당 소요 시간, 월 외주비, 현재 판매 비중·객단가 등 (3회차 효과 측정의 기준)
- **결과물:** AI 도입 진단표, 과제 정의서

### 2회차 · 솔루션 구축 & 실습
- **미팅 중:** 맞춤 AI 도구 계정 연동, 점주가 직접 프롬프트 실습 → 실제 매장 콘텐츠(상세페이지, SNS 숏폼, 챗봇 등) 1차 제작
- **과제:** 매장에서 1~2주 A/B 테스트 또는 파일럿 적용 (기간·지표·비교 대상을 미리 합의)
- **지속 가능성 확인:** 점주 혼자 5분 안에 다시 할 수 있는지 반복 실습
- **결과물:** 멘티 맞춤 프롬프트 팩, 1차 파일럿 제작물

### 3회차 · 효과 측정 & BM 완성
- **미팅 중:** 파일럿 전후 데이터 정리(제작 시간 절감률, 비용 절감, 고객 반응) → 사업화 자금 예산 계획 수립 → 발표평가용 5분 IR 덱 피드백과 모의 질의응답
- **결과물:** STEP 2 사업계획서, 발표평가 PPT 초안

## 9. AI 멘토링 기록과 보고서

기록 원칙은 6장과 같습니다. 보고 양식은 아직 확인되지 않았습니다 — 양식을 받으면 이 장과 앱의 생성 기능을 추가합니다. 그 전까지 회차별 결과물(8장)을 회차·기록 탭에 쌓아 둡니다.

### STEP 2 발표평가 대비: 심사위원의 3대 질문
1. **정말 소상공인이 직접 쓸 수 있는가? (지속가능성)** — 외주사나 멘토가 만들어 주고 떠나면 방치될 시스템을 가장 경계합니다. 근거: 점주가 직접 조작하는 실습을 반복 검증한 기록.
2. **비용이 얼마나 줄고 매출이 얼마나 느는가? (정량적 ROI)** — 기술보다 숫자. 근거: 1회차 기준값과 3회차 측정값 비교 (예: 인쇄물 외주비 월 40만 원 → AI 구독료 월 3만 원, 주력 메뉴 판매 비중 22% → 38% — 매뉴얼의 예시 수치).
3. **4,000만 원을 어떻게 효율적으로 쓸 것인가? (예산 타당성)** — 정부지원금 80% + 자부담 20%의 적정 배분.

### 사업비 구성 가이드 (매뉴얼 예시)

| 비목 | 권장 비중 | 주요 사용처 | 심사 대응 포인트 |
| --- | --- | --- | --- |
| AI 솔루션 활용비 | 20~30% | 유료 AI SaaS 구독료, API 사용료, 라이선스 | 장기적 자립 기반 |
| 시제품·기기 도입비 | 30~40% | 디지털 사이니지 모니터, 촬영 장비, 시제품 제작 | 매장 내 물리적 인프라 |
| 홍보·마케팅 집행비 | 20~30% | AI 생성 콘텐츠 기반 메타·인스타·네이버 광고비 | 실제 매출 전환 데이터 |
| 수수료 및 전문가비 | 10% 내외 | 지식재산권(상표권), 세무·회계 검토 | 사업 리스크 방어 |

## 11. 툴킷 템플릿

### 템플릿 A. 고객 정의(ICP) 4단계
1. **필수 조건:** 하나라도 불충족이면 제외 (예: 고객이 주문 전 화면을 보는 동선, 매장 내 소비 비중, 설치 공간·통신, 결정권자 직접 접촉)
2. **세분화 변수:** 점포 특성 / 운영·행동 / 니즈 / 구매 특성
3. **점수표 (100점):** 니즈 강도 25 · 지불 가능성 25 · 접근성 15 · 측정 용이성 15 · 시장 규모 10 · 대체재 취약도 10. 점수마다 근거가 '말'인지 '행동'인지 표기, 세그먼트당 최소 5곳 인터뷰 후 확정
4. **Beachhead:** 최고 점수 세그먼트 1개 + 인접 확장 경로 한 줄

### 템플릿 B. Mom Test 인터뷰 기록
- 매장명 / 업종 / 상권
- 최근 변경 일시와 방식 (직접 vs 외주)
- 실제 지출 비용과 소요 기간
- 가장 번거로운 지점
- 시범 제안 시 실제 행동: 거절 / 말로만 동의 / 자료 즉시 전달

### 템플릿 C. 파일럿 설계 (AI 멘토링의 A/B 테스트에도 사용)
- 대상 3~5곳 또는 매장 1곳 안의 비교 대상 (선정 기준 명시), 기간: 기준값 2주 → 개선 적용 2~4주 (AI 멘토링은 1~2주), 같은 요일끼리 비교
- 지표 3개 (예: 대표 상품 판매 비중, 객단가, 문의 횟수, 제작 시간), 내부 대조군, 성공 기준
- 사례 1장: 숫자 + 전후 사진 + 고객 한마디

### 템플릿 D. 단위 경제·투자 회수
- 거래당 필요 매출 증가액 = 월 구독료 ÷ (월 거래 건수 × 마진율)
- 단위당 공헌이익 = 월 구독료 − (월 제작 원가 + 기기 감가상각 + AS 안분)
- 기기 투자 회수 기간 = 기기 도입 원가 ÷ 월 공헌이익
- AI 도입 절감률 = (도입 전 월 비용 − 도입 후 월 비용) ÷ 도입 전 월 비용
